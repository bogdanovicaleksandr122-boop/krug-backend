# КРУГ — серверная часть (простыми словами)

Это тот самый "шкаф с папками" + "мозг приложения", о которых шла речь в чате. Пока это просто набор файлов на твоём компьютере — чтобы всё заработало по-настоящему, нужно несколько шагов. Не пытайся разобраться в самих файлах — это не нужно, просто следуй шагам ниже, а если что-то непонятно — присылай мне, что видишь на экране, и я подскажу дальше.

## Что нужно сделать (по порядку)

1. **Завести аккаунт на Railway** (railway.app) — это сервис, который будет держать приложение включённым 24/7. Есть бесплатный пробный период.
2. **Создать там же базу данных Postgres** — это и есть "шкаф с папками". Railway создаёт её в два клика, никаких настроек вручную не нужно.
3. **Загрузить эти файлы в Railway** — обычно через GitHub (бесплатный сервис для хранения кода). Я помогу пошагово, когда дойдём до этого шага.
4. **Получить токен бота** — если у тебя ещё нет Telegram-бота для КРУГ, напиши об этом, я подскажу, как получить токен через @BotFather (это стандартный бот Telegram для создания других ботов).
5. **Вписать несколько секретных значений** в настройках Railway (токен бота, пароль для входа в админку и т.п.) — я дам точный список, когда дойдём до этого шага.
6. Дальше всё запустится само, и мы подключим уже готовый прототип (внешний вид приложения) к этому серверу.

## Что уже готово внутри

- Все категории, города и тестовые анкеты специалистов — те же, что в текущем прототипе.
- Проверка "это правда я" через Telegram — без смс и лишних действий.
