# КРУГ — серверная часть (контекст для Claude)

## Что за проект
КРУГ — Telegram мини-приложение, справочник специалистов-эмигрантов, которые оказывают услуги «своим» за границей. Старт — Польша и Болгария, дальше другие страны ЕС.

Проект состоит из двух репозиториев:
- **krug-backend** (этот): сервер Node.js + Express + Prisma + PostgreSQL, работает на Railway.
- **krug-app**: фронтенд — статические файлы `index.html` (само мини-приложение), `admin.html` (админка), `privacy.html`. Хостинг — GitHub Pages. Адрес API прописан в `API_BASE` внутри html-файлов.

Бот: @krugspace_bot, мини-приложение открывается по `t.me/krugspace_bot/app`, анкета — `?startapp=spec_<id>`.

## Как устроен деплой
- Railway автоматически пересобирает сервер после изменений в ветке `main` на GitHub.
- `npm start` = `prisma db push --accept-data-loss && node prisma/seed.js && node src/server.js`.
- `prisma/seed.js` запускается при каждом старте, поэтому он только **добавляет недостающее** (категории, города; демо-анкеты — только в пустую базу) и ничего не перезаписывает. Он же выставляет счётчик номеров анкет после максимального (демо-анкеты занимают 101–109).
  ⚠️ `--accept-data-loss`: если из схемы убрать поле/таблицу, данные удалятся без предупреждения. Схему меняем только добавлением, удаление — только осознанно и с бэкапом.
- Признаки успешного запуска в логах: «КРУГ backend запущен», «Шрифты для карточек загружены».
- Если сборка упала, Railway молча оставляет работать старую версию — проверять вкладку Deployments.

## Переменные окружения (Railway)
`DATABASE_URL`, `BOT_TOKEN`, `JWT_SECRET`, `ADMIN_TELEGRAM_IDS`, `ALLOWED_ORIGINS`, `TELEGRAM_WEBHOOK_SECRET`. Необязательные: `BOT_USERNAME` (по умолчанию krugspace_bot), `MINI_APP_NAME` (app), `PUBLIC_API_URL`, `BACKUP_CHAT_ID` (куда слать бэкапы; по умолчанию `TELEGRAM_FILE_RELAY_CHAT_ID`).

## Бэкапы базы
- Раз в сутки сервер выгружает все таблицы (список берётся из схемы Prisma автоматически) в `krug-backup-ГГГГ-ММ-ДД.json.gz` и шлёт файлом в Telegram (`src/lib/backup.js`). Время последней копии и последняя ошибка — в `AppSetting` (`backup_last_at`, `backup_last_error`). В админке вкладка «Бэкапы»: статус, «Сделать копию сейчас», выгрузка анкет в CSV (формат совместим с «Импорт CSV»).
- Восстановление: `npx prisma db push`, затем `node prisma/restore.js файл.json.gz` (только в пустую базу; `--wipe` — очистить и заменить). Проверено: копия → восстановление → повторная копия побайтно совпадает.
- При изменении схемы (новые поля/таблицы) бэкап подхватит их сам; если поле переименовано/удалено — старый бэкап нужно будет подправить перед восстановлением.

## Вход в админку
- Основной вход — через Telegram-аккаунт (официальный виджет Telegram Login на `admin.html`). Разрешённые аккаунты — Telegram ID через запятую в `ADMIN_TELEGRAM_IDS`. Для работы виджета домен страницы админки привязан к боту в @BotFather (`/setdomain`).
- Пока `ADMIN_TELEGRAM_IDS` пустая — работает старый вход по `ADMIN_USERNAME`/`ADMIN_PASSWORD` (чтобы не потерять доступ при обновлении). Как только задана — вход по паролю отключён, а старые входы по паролю перестают действовать.
- `adminAuth` при каждом запросе сверяет `tgId` из токена со списком: убрали ID из переменной — доступ пропал сразу. Экстренный сброс всех входов — сменить `JWT_SECRET`.
- О каждом входе бот пишет всем админам (кто, когда, IP, устройство). Логика — `src/lib/adminAccess.js`.

## Устройство кода
- `src/server.js` — точка входа, подключение роутов, почасовое снятие истёкших PRO/буст.
- `src/routes/public.js` — каталог, категории, города, анкета, подача анкеты, фото.
- `src/routes/me.js` — личный кабинет (всё под `telegramAuth`): свои анкеты, избранное, поддержка.
- `src/routes/admin.js` — админка (JWT): модерация, правка, CSV-загрузка, статистика, цены, рассылка.
- `src/routes/payments.js` — оплата звёздами (PRO, буст) + **вебхук бота** `/api/telegram/webhook` (платежи, ответы поддержки, inline-поиск).
- `src/routes/share.js` — картинка-карточка анкеты `share-card.jpg` и подготовка сообщения для `Telegram.WebApp.shareMessage`.
- `src/lib/shareCardDraw.js` — рисование карточки (Canvas 2D), `shareCard.js` — шрифты (Unbounded/Manrope скачиваются из Google Fonts при запуске), фото, кэш.
- `src/lib/shareMessage.js` — общая сборка сообщения «карточка + кнопка Открыть анкету».
- `src/lib/inlineSearch.js` — поиск через `@krugspace_bot запрос` в любом чате.
- `src/routes/track.js` — сбор статистики из приложения: `/api/track/open` (открытие приложения, источник — из подписанного `start_param`) и `/api/track/event` (просмотр анкеты, нажатие на контакт, «поделиться»; повторы одного человека за 30 мин не считаются, владелец сам себя не накручивает).
- `src/routes/adminAnalytics.js` — подключён внутри `admin.js` (под JWT): `/analytics` (вся статистика за период), `/specialists/:id/stats`, CRUD рекламных ссылок `/referrals`.
- `src/lib/analytics.js` — все расчёты статистики (дни/часы по времени `Europe/Sofia`). Статистику анкеты владелец получает через `GET /api/me/specialists/:id/stats` (только verified-владелец, только количество, без имён).
- `src/lib/specialistData.js` — какие поля анкеты отдаются публично (`PUBLIC_SELECT`/`toPublic`: без Telegram ID подавшего, правок на проверке, причин отказа), проверка и нормализация ввода анкеты (`cleanListingInput`), разбор контактов, условия «город + онлайн по стране» и «подкатегория + доп. подкатегории PRO», порядок в списках.
- `src/lib/search.js` — общий поиск для приложения и inline-поиска (окончания слов, услуги, категории, подкатегории, города).
- `src/lib/notifications.js` — напоминания за 3 дня до конца PRO/буста и недельная сводка просмотров (по понедельникам, 10–20 ч по Софии). Ссылки в кнопках: `startapp=cab_<id>_pro|boost|stats`.
- `src/lib/subscriptions.js` — отмена подписки PRO (при удалении анкеты).
- `src/lib/asyncRoute.js` — обёртка для async-роутов: Express 4 не ловит ошибки в async, без обёртки ошибка базы роняет весь сервер. Новые роуты писать через неё.
- `src/middleware/telegramAuth.js` — проверка initData (подпись + срок 24 ч); ставит `req.isNewTelegramUser`, `req.telegramStartParam`. `optionalTelegramUser` — для публичных роутов (без записи в базу).
- Публичный номер анкеты = id + 100000000000 (`lib/publicId.js`).

## Принятые решения по продукту
- Анкеты от пользователей проходят модерацию. Отзывов и рейтингов нет (сложно контролировать честность). Вместо них — «Рекомендую»: один голос с одного аккаунта Telegram, без текста, видно только количество (таблица `Recommendation`); свою анкету рекомендовать нельзя. Чаще рекомендуемые стоят выше среди обычных анкет.
- Правка опубликованной анкеты НЕ скрывает её: правки лежат в `pendingChanges`, в каталоге до проверки — прежняя версия; очередь модерации ищет и по `pendingChanges`. Неопубликованная анкета правится напрямую и целиком идёт на проверку.
- «Онлайн / по всей стране» (`worksOnline`): анкета видна во всех городах страны своего города.
- PRO — подписка Telegram Stars (30 дней, `proRecurring`), при ошибке — разовая оплата на месяц; пока действует разовый PRO, предлагается разовое продление на месяц от конца срока. Даёт: место выше, бейдж, доп. подкатегории (`extraSubcategories`, действуют только при активном PRO), приоритет в очереди модерации, полную статистику. Повторная покупка PRO/буста продлевает срок от текущего конца. Повтор уведомления об оплате не засчитывается (проверка `telegramPaymentChargeId`). Если анкеты нет — звёзды возвращаются автоматически. История платежей не удаляется вместе с анкетой.
- Пробный буст 3 дня бесплатно — один раз на анкету (`trialBoostUsedAt`).
- Языки у анкет не используются (поле `langs` осталось в базе только ради старых данных).
- Кто добавил чужую анкету — видит её в кабинете, но управлять не может: только кнопка «Подтвердить владение». Редактирование, удаление, фото, PRO/буст, статистика — только подтверждённому владельцу (`verified`), это же проверяет сервер. Подтверждение: автоматически по совпадению Telegram, иначе заявка с кодом (`/api/me/specialists/:id/claim-request`) уходит в служебный чат, владелец назначается в админке.
- Статистика анкеты: без активного PRO/буста — только просмотры; с PRO или бустом — полная (сервер сам урезает ответ, `limited: true`).
- Карточка специалиста: разные контакты (Telegram/Instagram/телефон/сайт), опционально адрес.
- 14 основных категорий с подкатегориями. Окончательный список — после наполнения базы по Польше и Болгарии; Claude может сам добавлять категории/подкатегории, если существующие не подходят.
- Первичную базу анкет владелец собирает сам (Instagram, Telegram-чаты).
- Дизайн: минималистичный чёрно-белый, жирный шрифт, круглый логотип «КРУГ».
- Монетизация сейчас: PRO и буст за звёзды Telegram. Идеи на будущее: «Партнёр недели», аналитика просмотров для специалиста, партнёрские сервисы.

Владелец подтверждённой анкеты видит её статистику в «Мои услуги» → «Статистика».
- Аудит и большое обновление (окт. 2026): защита данных в публичных ответах, лимиты запросов по аккаунту Telegram (вебхук и фото — без общего лимита), проверка ввода анкет, подписка PRO, напоминания и недельная сводка, приветствие бота на /start, поиск один для приложения и бота, подборки на главной (`GET /api/home`), проверка повторов (`POST /api/specialists/check-duplicates`), фото при подаче анкеты (`/api/me/specialists/:id/submission-photo`), «Рекомендую», тёмная тема, кнопка «Назад» Telegram.
