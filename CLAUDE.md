# КРУГ — серверная часть (контекст для Claude)

## Что за проект
КРУГ — Telegram мини-приложение, справочник специалистов-эмигрантов, которые оказывают услуги «своим» за границей. Старт — Польша и Болгария, дальше другие страны ЕС.

Проект состоит из двух репозиториев:
- **krug-backend** (этот): сервер Node.js + Express + Prisma + PostgreSQL, работает на Railway.
- **krug-app**: фронтенд — статические файлы `index.html` (само мини-приложение), `admin.html` (админка), `privacy.html`. Хостинг — GitHub Pages. Адрес API прописан в `API_BASE` внутри html-файлов.

Бот: @krugspace_bot, мини-приложение открывается по `t.me/krugspace_bot/app`, анкета — `?startapp=spec_<id>`.

## Как устроен деплой
- Railway автоматически пересобирает сервер после изменений в ветке `main` на GitHub.
- `npm start` = `prisma db push --accept-data-loss && node prisma/seed.js && node src/server.js`.
  ⚠️ `--accept-data-loss`: если из схемы убрать поле/таблицу, данные удалятся без предупреждения. Схему меняем только добавлением, удаление — только осознанно и с бэкапом.
- Признаки успешного запуска в логах: «КРУГ backend запущен», «Шрифты для карточек загружены».
- Если сборка упала, Railway молча оставляет работать старую версию — проверять вкладку Deployments.

## Переменные окружения (Railway)
`DATABASE_URL`, `BOT_TOKEN`, `JWT_SECRET`, `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `ALLOWED_ORIGINS`, `TELEGRAM_WEBHOOK_SECRET`. Необязательные: `BOT_USERNAME` (по умолчанию krugspace_bot), `MINI_APP_NAME` (app), `PUBLIC_API_URL`.

## Устройство кода
- `src/server.js` — точка входа, подключение роутов, почасовое снятие истёкших PRO/буст.
- `src/routes/public.js` — каталог, категории, города, анкета, подача анкеты, фото.
- `src/routes/me.js` — личный кабинет (всё под `telegramAuth`): свои анкеты, избранное, поддержка.
- `src/routes/admin.js` — админка (JWT): модерация, правка, CSV-загрузка, статистика, цены, рассылка.
- `src/routes/payments.js` — оплата звёздами (PRO, буст) + **вебхук бота** `/api/telegram/webhook` (платежи, ответы поддержки, inline-поиск).
- `src/routes/share.js` — картинка-карточка анкеты `share-card.jpg` и подготовка сообщения для `Telegram.WebApp.shareMessage`.
- `src/lib/shareCardDraw.js` — рисование карточки (Canvas 2D), `shareCard.js` — шрифты (Unbounded/Manrope скачиваются из Google Fonts при запуске), фото, кэш.
- `src/lib/shareMessage.js` — общая сборка сообщения «карточка + кнопка Открыть анкету».
- `src/lib/inlineSearch.js` — поиск через `@krugspace_bot запрос` в любом чате.
- `src/routes/track.js` — сбор статистики из приложения: `/api/track/open` (открытие приложения, источник — из подписанного `start_param`) и `/api/track/event` (просмотр анкеты, нажатие на контакт, «поделиться»; повторы одного человека за 30 мин не считаются, владелец сам себя не накручивает).
- `src/routes/adminAnalytics.js` — подключён внутри `admin.js` (под JWT): `/analytics` (вся статистика за период), `/specialists/:id/stats`, CRUD рекламных ссылок `/referrals`.
- `src/lib/analytics.js` — все расчёты статистики (дни/часы по времени `Europe/Sofia`). Статистику анкеты владелец получает через `GET /api/me/specialists/:id/stats` (только verified-владелец, только количество, без имён).
- `src/lib/asyncRoute.js` — обёртка для async-роутов: Express 4 не ловит ошибки в async, без обёртки ошибка базы роняет весь сервер. Новые роуты писать через неё.
- `src/middleware/telegramAuth.js` — проверка initData (подпись + срок 24 ч); ставит `req.isNewTelegramUser`, `req.telegramStartParam`. `optionalTelegramUser` — для публичных роутов (без записи в базу).
- Публичный номер анкеты = id + 100000000000 (`lib/publicId.js`).

## Принятые решения по продукту
- Анкеты от пользователей проходят модерацию. Отзывов и рейтингов нет (сложно контролировать честность).
- Карточка специалиста: разные контакты (Telegram/Instagram/телефон/сайт), опционально адрес.
- 14 основных категорий с подкатегориями. Окончательный список — после наполнения базы по Польше и Болгарии; Claude может сам добавлять категории/подкатегории, если существующие не подходят.
- Первичную базу анкет владелец собирает сам (Instagram, Telegram-чаты).
- Дизайн: минималистичный чёрно-белый, жирный шрифт, круглый логотип «КРУГ».
- Монетизация сейчас: PRO и буст за звёзды Telegram. Идеи на будущее: «Партнёр недели», аналитика просмотров для специалиста, партнёрские сервисы.

## Что уже сделано недавно
- Кнопка «поделиться» отправляет красивую карточку-картинку с кнопкой (как чек в @send); при ошибке приложение делится обычной ссылкой.
- Inline-поиск: `@krugspace_bot стоматолог Варна` в любом чате показывает карточки анкет. Inline Mode в BotFather включён.
- Статистика и реклама: рекламные ссылки `t.me/krugspace_bot/app?startapp=r_<код>` создаются в админке (вкладка «Реклама»), можно указать стоимость (считается цена нового пользователя) и анкету, которая откроется сразу. Источник первого входа пишется в `TelegramUser.firstSource/referralLinkId` один раз. Таблицы `AppOpen`, `SpecialistEvent`, `SearchLog` — сырые события, старше 400 дней удаляются раз в сутки. Владелец подтверждённой анкеты видит её статистику в «Мои услуги» → «Статистика».
